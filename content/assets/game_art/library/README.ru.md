# Картинки библиотеки гримуаров

Положите PNG в эту папку (рекомендуемый размер баннера ~1280×720).

| Файл | Где показывается |
|------|------------------|
| `grimoire_library.png` | Главный зал библиотеки |
| `class_warrior.png` | Каталог воина |
| `class_mage.png` | Каталог мага |
| `class_scout.png` | Каталог разведчика |
| `class_acolyte.png` | Каталог жреца |
| `class_necromancer.png` | Каталог некроманта (высшие гримуары) |

Если файла нет — используется `menus/home_library.png` или экран без баннера.
