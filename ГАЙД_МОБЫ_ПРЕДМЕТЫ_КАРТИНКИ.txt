================================================================================
  ГАЙД: как самому менять мобов, предметы и картинки (бот «Башня»)
================================================================================
Корень кода бота: папка tower_bot (рядом с этим файлом лежит game/, bot/, assets/).

Формат картинок: PNG. Для Telegram удобно не гигантские файлы (до ~2–5 МБ норм).


--------------------------------------------------------------------------------
1. ИМЕНА И ОПИСАНИЯ МОНСТРОВ (без картинок)
--------------------------------------------------------------------------------
Файл:  game/floors/monsters.py

Что там есть:
  - Обычные мобы зоны — в словаре внутри функции _pool(zone_key): шаблоны
    MonsterTemplate(key, name, emoji, element, blurb).
  - Мини-босс зоны — функция mini_boss_for_zone(): одна строка на зону.
  - Сильный босс (каждый 10-й этаж зоны) — major_boss_for_zone().

Важно:
  - Поле key (первый аргумент MonsterTemplate) — технический идентификатор.
    Его лучше НЕ переименовывать без поиска по всему проекту: в балансе,
    квестах, античите могут быть ссылки на тот же ключ.
  - Поле name — то, что видит игрок. Его можно менять свободно.
  - emoji — иконка в списке на этаже.

После правок перезапусти бота (Python-процесс).


--------------------------------------------------------------------------------
2. ПОРТРЕТ МОНСТРА НА ЭКРАНЕ БОЯ (фото сверху, подпись — текст боя)
--------------------------------------------------------------------------------
Сейчас портреты задаются явной таблицей «ключ шаблона → файл».

Файл кода:   game/floors/monster_portraits.py
Папка PNG:   tower_bot/assets/monsters/

Шаги:
  1) Узнай template_key нужного моба в monsters.py (например mini_alpha_wolf).
  2) Положи файл PNG в assets/monsters/ с ЛЮБЫМ именем, но в коде укажи
     относительный путь от корня tower_bot, например:
       "assets/monsters/mini_alpha_wolf.png"
  3) В monster_portraits.py в словарь _BATTLE_PORTRAIT_FILES добавь строку:
       "ключ_шаблона": "assets/monsters/твой_файл.png",
     либо замени путь у существующего ключа.
  4) Перезапусти бота.

Условие показа:
  - В настройках персонажа должны быть ВКЛЮЧЕНЫ игровые картинки
    (см. раздел 5).
  - Файл должен реально существовать по пути — иначе портрет не покажется.

Лимит Telegram: подпись к фото до ~1024 символов; длинные экраны награды
бот сам переводит в обычное текстовое сообщение.


--------------------------------------------------------------------------------
3. КАРТИНКА ФОНА ЭТАЖА (не монстр)
--------------------------------------------------------------------------------
Файл логики:  utils/image_assets.py  →  location_image_for_floor()
Папка:        tower_bot/assets/images/locations/

Приоритет для этажа N:
  1) floor_N.png     (например floor_5.png)
  2) картинка зоны   имя = ключ зоны из floor_data + .png
  3) default.png

Подменяешь/добавляешь PNG — перезапуск бота.


--------------------------------------------------------------------------------
4. КАРТИНКИ ПРЕДМЕТОВ (инвентарь, лут с image_url)
--------------------------------------------------------------------------------
Файл путей:  game/items/equipment/item_asset_paths.py
Функция:     item_gear_png("stem")  →  файл  tower_bot/assets/items/stem.png

Типичный сценарий — элик / дроп в loot.py:
  В словаре предмета есть поле:
    "image_url": item_gear_png("elite_ether"),
  Тогда нужен файл:
    tower_bot/assets/items/elite_ether.png

Шаги:
  1) Придумай stem (латиница, без пробелов), например my_potion.
  2) Положи my_potion.png в tower_bot/assets/items/.
  3) В описании предмета (loot.py или генератор экипировки) укажи:
       "image_url": item_gear_png("my_potion"),
  4) Перезапуск бота.

Если картинки в настройках ВЫКЛЮЧЕНЫ — предмет в инвентаре откроется без фото,
только текст (см. раздел 5).


--------------------------------------------------------------------------------
5. ОБЩИЙ ФЛАГ «ПОКАЗЫВАТЬ КАРТИНКИ В ИГРЕ»
--------------------------------------------------------------------------------
Код:  utils/game_images_prefs.py
  - game_images_enabled(character) — картинки включены, если в meta_progress
    НЕТ флага hide_game_images.

Что подчиняется этому флагу (идея):
  - фон этажа, меню с картинкой, профиль с портретом, портреты в бою из
    monster_portraits, карточка предмета в инвентаре с image_url и т.д.

Где переключается в боте — экран настроек (handlers/settings.py): туда
пишется meta_progress через set_game_images_hidden.


--------------------------------------------------------------------------------
6. ДРУГИЕ КАРТИНКИ (справка)
--------------------------------------------------------------------------------
  - Меню «хаб»:  tower_bot/assets/images/menu_hub.png
  - Портреты при регистрации: assets/images/profile/ (см. start.py и
    utils/profile_portraits.py)
  - В image_assets.py monster_image_for_template() смотрит тот же каталог, что
    и портрет боя: assets/monsters/{key}.png (см. раздел 2).


--------------------------------------------------------------------------------
7. ЧТО ПРОВЕРИТЬ, ЕСЛИ «НЕ ВИДНО КАРТИНКУ»
--------------------------------------------------------------------------------
  - Имя файла и расширение .png совпадают с путём в коде (регистр важен на Linux).
  - Файл лежит внутри tower_bot/assets/... как в гайде.
  - Бот перезапущен после изменений.
  - У персонажа включены игровые картинки в настройках.
  - Для боя: ключ в _BATTLE_PORTRAIT_FILES совпадает с template_key моба.
