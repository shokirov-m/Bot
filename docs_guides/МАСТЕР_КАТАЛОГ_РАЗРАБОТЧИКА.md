## 0. Как устроен поток данных

Упрощённая цепочка (сверху вниз):

```
Telegram update
 → bot/middlewares/     (очередность: throttle → DB session → auth → activity)
 → bot/handlers/*.py    (парсинг callback/text, только UI — без тяжёлой логики)
 → services/*_service.py (бизнес-логика, commit сессии)
 → db/repository/*.py    (SQL)
 → db/models/*.py       (ORM)
 → game/**/*            (расчёты: бой, этажи, квесты, формулы)
 → bot/keyboards/*_kb.py (кнопки)
 → bot/i18n.py          (строки, если вынесены)
```

**Правило:** правка поведения фичи почти всегда = **`services/<feature>_service.py`** + **`bot/handlers/<feature>.py`**; чистые формулы = **`game/`**.

## 4. NPC, квесты, награды

### 4.1. Общая схема

1. **Данные:** что за квест, условие, текст награды — `game/quests/*.py`.  
2. **Логика:** проверки, начисление, запись прогресса — `services/*_quest_service.py` или узкий сервис фичи.  
3. **UI:** сообщения и кнопки — `bot/handlers/*.py`.

### 4.2. Таблица: тема → файлы данных → сервис → хендлер

| Тема | Данные (`game/quests/`) | Сервис | Хендлер UI |
|------|-------------------------|--------|------------|
| Городские квесты | `city_quests.py` | `services/city_quest_service.py` | `bot/handlers/city_quests.py` |
| Квесты привязанные к этажам | `floor_quests.py` | часто через `quest_service` / `floor_service` | `bot/handlers/quests.py`, `floor.py` |
| Ежедневные задания | `daily_quests.py` | `services/daily_quest_service.py` | `bot/handlers/daily.py` |
| Кузнец (цепочки) | `forge_quests.py` | `services/forge_quest_service.py` | `bot/handlers/forge.py` |
| Скупщик в таверне | `tavern_buyer_quests.py` | `services/tavern_buyer_service.py` | `floor.py` / таверна |
| Бродячие NPC | `wandering_npc_quests.py` + `game/floors/wandering_npcs.py` | `services/wandering_npc_quest_service.py` | `forest_beginnings.py`, `floor.py` |
| Сюжет этажа 1 (Эйрис, Сова, Рэнд) | **`story_quests.py`** | логика в самом модуле + счётчики из **`combat_service.py`** для прогресса | **`bot/handlers/floor.py`** (`sq:*`) |
| Общие NPC-квесты (если используются) | `npc_quests.py` | зависит от места вызова | искать импорт в handlers |

### 4.3. Прогресс квестов в БД

| Что меняете | Файл |
|-------------|------|
| ORM строка прогресса | `db/models/quest.py` |
| CRUD по квестам | `db/repository/quest_repo.py` |
| Фасад квестов | `services/quest_service.py` |

### 4.4. Добавление **нового** квеста (чек-лист)

1. Описать квест в `game/quests/<тип>_quests.py`.  
2. Если нужна БД — убедиться, что ключ квеста пишется в `quest_progress` (репозиторий).  
3. Реализовать выдачу награды в **`services`** (не в handler).  
4. Добавить кнопки / колбэки в **`bot/handlers`** + **`bot/keyboards`** при необходимости.  
5. Зарегистрировать роутер, если новый файл (см. §12).

## 15. Чек-листы типовых задач

### «Сделать этаж N уникальным»

1. `floor_data.py` — зона / город / тип.  
2. `monsters.py` — список спавнов.  
3. При особой механике — новый модуль в `game/floors/` + ветку в **`floor.py`**.  
4. Награды — `rewards.py` и/или **`combat_service.py`**.

### «Добавить нового торговца / товар»

1. Если расходник в лавке за золото — **`game/economy/shop.py`**.  
2. Логика покупки — **`shop_service.py`**.  
3. Клавиатуру поправить в **`handlers/shop.py`** или генератор kb.

### «Новый NPC с квестом»

1. Данные в **`game/quests/<тип>_quests.py`**.  
2. Сервис с проверкой и наградами — **`services/...`** (новый или существующий).  
3. UI — **`bot/handlers`** + возможно доп. колбэки в **`floor.py`**.

### «Событие по расписанию»

**`scheduler/tasks.py`** + при необходимости запись в **`AppGlobal`** / отдельный сервис.

## 16. Предостережения

1. **`game/data/monsters_catalog.json`** — только валидный JSON; ошибка синтаксиса **убивает весь старт**.  
2. **`game/data/*`**, **`game/balance.py`**, **`game/crafting/recipes.py`** — очень большие; не открывать «на всякий случай».  
3. **`services/combat_service.py`** и **`services/clan_service.py`** — огромные; править точечные блоки через поиск (`grep`/поиск в IDE).  
4. После правок ORM — **Alembic** + синхронизация с кодом репозиториев.
