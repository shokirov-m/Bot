# Мастер-каталог для разработчика «Башня испытаний»

Один файл-навигатор: **что менять** → **в каких модулях**.  
Корень проекта бота: `tower_bot/`.

---

## 1. Этажи: номер, зона, город, «уникальная механика»

| Задача | Где править |
|--------|-------------|
| Какой этаж к какой зоне относится, ключ зоны, тип этажа | `game/floors/floor_data.py` |
| Статичные таблицы этажей (если дублируются в data) | `game/data/floors.py` *(большой файл, открывать по необходимости)* |
| Список монстров **на этаже** (спавны, слоты) | `game/floors/monsters.py` |
| Формула HP/ATK/DEF монстра по этажу (кривые, множители 20+, боссы) | `game/floors/monster_stat_formula.py` + константы в `game/balance.py` |
| Редкие «особые» сценарии этажа (волны, комнаты, длинные этажи) | `game/floors/explore_floor*.py`, `room_clear_floor*.py`, `wave_floor*.py`, `long_floor.py` и др. по имени зоны |

**UI этажа (кнопки, переход)**  
- Логика кнопок: `bot/handlers/floor.py`  
- Клавиатура: `bot/keyboards/floor_kb.py`  
- Оркестрация путешествий: `services/floor_service.py`

## 2. Монстры: карточки, имена, зоны в пулах

## 5. NPC, диалоги, квесты, награды

Принцип: **данные квеста** в `game/quests/`, **кнопки и текст в чате** в `bot/handlers/`, **правила выдачи наград** в `services/*_quest_service.py`.

| Тема | Данные / правила | UI (Telegram) |
|------|------------------|---------------|
| Квесты города | `game/quests/city_quests.py` | `bot/handlers/city_quests.py` |
| Квесты этажей | `game/quests/floor_quests.py` | через `floor` / `quests` хендлеры |
| Ежедневные | `game/quests/daily_quests.py` | `bot/handlers/daily.py`, `services/daily_quest_service.py` |
| Кузнец / скупщик | `game/quests/forge_quests.py`, `tavern_buyer_quests.py` | `forge`, `floor` (скупщик) |
| Бродячие NPC на этажах | `game/floors/wandering_npcs.py`, `game/quests/wandering_npc_quests.py` | `bot/handlers/forest_beginnings.py` / `floor` (см. колбэки), `services/wandering_npc_quest_service.py` |
| **Сюжетные NPC этажа 1** | `game/quests/story_quests.py` | `bot/handlers/floor.py` (колбэки `sq:*`) |

**Общий роутер квестов**  
- `services/quest_service.py`  
- Репозиторий прогресса: `db/repository/quest_repo.py`, модель `db/models/quest.py`

### Важные предостережения

1. **`game/data/monsters_catalog.json`** — должен быть **валидным JSON**. Одна ошибка вида `"gold": ,` останавливает запуск бота.  
2. **`game/balance.py`**, большие **`game/data/*`** и **`game/crafting/recipes.py`** — тяжёлые файлы; открывать только под конкретную правку (см. `.cursor/rules/02-dev-workflow.mdc`).  
3. После смены **схемы БД** — миграция Alembic в `tower_bot/` (правила архитектуры).
